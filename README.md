## 1. Overview & Scope

This repository is the self-contained open research package for the flagship report **"China's Green Compute Global Delivery System and International Value Restructuring"** (《中国绿色算力全球化交付体系与国际价值重构》) authored by **JIEZIJIUWEI（介子九维）**. For the report's core findings, quantitative takeaways (`01`–`06`), and analytical synthesis, please read the [English Executive Summary (`manuscript/en/executive-summary.md`)](manuscript/en/executive-summary.md), the [Chinese Executive Summary (`manuscript/zh-CN/executive-summary.md`)](manuscript/zh-CN/executive-summary.md), and the [Full 12-Chapter Chinese Manuscript (`manuscript/zh-CN/index.md`)](manuscript/zh-CN/index.md). Organized in native GitHub Flavored Markdown (GFM), CSV, JSON, and Python, this package provides:

1. **Complete 12-Chapter Chinese Manuscript ([`manuscript/zh-CN/`](manuscript/zh-CN/index.md), 17 files):** Unabridged Markdown text covering the Master Index (`index.md`), Front Matter & Methodology (`front-matter-and-methodology.md`), Executive Summary (`executive-summary.md`), Parts I–VI (Chapters 1–12 in `chapter-01.md`..`chapter-12.md`, 54 sections, 98 Exhibits including 55 statistical figures + 43 inline GFM tables, and 12 Thematic Callout Boxes), 14 Endnotes (`notes.md`, `[i]`–`[xiv]`), and 126 Formal References (`references.md`, `[1]`–`[126]`).
2. **Complete English Executive Summary & Chapter Crosswalk ([`manuscript/en/`](manuscript/en/index.md)):** Full English translation of the Executive Summary ([`manuscript/en/executive-summary.md`](manuscript/en/executive-summary.md), including Takeaways `01`–`06` and Sections `ES.1`–`ES.3`) and a 12-chapter bilingual navigation index.
3. **76 Catalogued CSV Datasets & 43 Inline Exhibit Table Snapshots ([`data/`](data/metadata/data_catalog.csv)):** [`data/metadata/data_catalog.csv`](data/metadata/data_catalog.csv) catalogues **76 CSV tables**, comprising **59 processed research tables** in `data/processed/` (58 `processed_reference` tables + 1 formula reference table `TBL-071_测算公式与适用范围.csv`) and **17 reproducible model output tables** in `data/models/` (`reported_model_snapshot`). In addition, `data/exhibits/` provides **43 standalone CSV snapshots** corresponding 1-to-1 to the 43 inline manuscript tables (`exhibit-es-3.csv` through `exhibit-12-9.csv`, registered in [`data/metadata/report_table_registry.json`](data/metadata/report_table_registry.json)).
4. **Parameterized Python Modeling & Figure Rendering Pipeline ([`src/`](src/models_engineering.py) & [`tools/`](tools/reproduce.py)):** All 17 model CSV tables and 56 figure pairs (`.png` at 350 DPI and `.svg` stored side-by-side in `figures/`) are deterministically generated by `src/models_engineering.py`, `src/models_analytics.py`, and `src/render_figures.py` using 4 centralized JSON parameter files in `data/parameters/`.

## 4. Quick Start: Reproduction & Package Verification

### 1. Tested Runtime Environment

Independent two-run reproduction was verified on a pre-existing local scientific Python environment recorded in [`docs/tested_environment.json`](docs/tested_environment.json):
- **OS & Python:** macOS (`Darwin 25.3.0 arm64`), Python **`3.14.5`**
- **Core Packages:** `numpy==2.4.3`, `pandas==3.0.3`, `scipy==1.18.0`, `cvxpy==1.9.3`, `scs==3.3.1`, `duckdb==1.5.4`, `networkx==3.7`, `pandera==0.34.1`, `SALib==1.6.0`, `statsmodels==0.15.0`, `matplotlib==3.11.2` (see root [`requirements.txt`](requirements.txt) and [`docs/tested_environment.json`](docs/tested_environment.json)).
- **Scope Note:** Because verification was executed in an existing local environment rather than a fresh clean install across older Python versions, compatibility with untested Python versions is not guaranteed.

### 2. Re-running the 17 Quantitative Models and 56 Figures

```bash
# Re-run all 17 model CSV tables and re-render all 56 figure pairs (defaults to reproduced/models/ and reproduced/charts/)
python3 tools/reproduce.py --models --figures

# Re-run only the 17 model CSV tables into a custom directory
python3 tools/reproduce.py --models --output-dir reproduced_models_only
```

- **Default Output Directories:** `tools/reproduce.py` writes outputs to `reproduced/models/` (17 CSV tables) and `reproduced/charts/` (56 `.png` and `.svg` pairs stored side-by-side) by default, preserving the published snapshots in `data/models/` and `figures/`.
- **Measured Elapsed Time:** In the verified environment, a full `--models --figures` run completed in **`33.33` seconds** (`models_engineering.py` `1.42s`, `models_analytics.py` `4.65s`, `render_figures.py` `27.19s`), and a second `--models`-only run completed in **`2.97` seconds** (`0.79s` + `2.14s`). All 17 CSVs and 56 PNGs matched byte-for-byte across runs.

### 3. Running the Structural & Integrity Validator

```bash
python3 tools/check_package.py
```

- **What `check_package.py` Verifies:** `tools/check_package.py` is a static package structure and metadata validator (**it does not re-execute the 17 numerical models**). It checks required directories and files, JSON/CSV validity, Markdown relative links and heading/explicit anchors, consistency across the 98 exhibits and 43 inline tables, zero leakage of local filesystem paths or internal workspace tokens, and byte/SHA-256 integrity against [`manifest.csv`](manifest.csv) (`path,bytes,sha256`).
